카카오맵 JavaScript API 설정

카카오 개발자 콘솔에서 JavaScript 키를 발급하고 GitHub Pages 주소를 JavaScript SDK 도메인으로 등록해야 합니다.

키는 이 브라우저의 로컬 저장소에만 보관됩니다. Kakao JavaScript 키는 웹페이지에서 사용하도록 설계된 공개형 키이며, REST API 키나 Admin 키를 입력하면 안 됩니다.
