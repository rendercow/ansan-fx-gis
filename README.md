FXGIS v0.5.2 — 아이콘 디자인 수정

전화걸기/길찾기 버튼의 이모지를 제거하고 기존 디자인 예시와 같은 간결한 녹색 수화기/파란색 자동차 SVG로 교체했습니다. 두 버튼 모두 시연용이며 전화나 내비게이션 앱을 실행하지 않습니다. 다른 기능은 v0.5.1과 동일합니다.

# FXGIS v0.5.1 — 모바일 조회·주변업체 개선

변경 사항:
- 업체목록과 주변업체 결과의 상호 앞에 동일 팔레트의 위험등급 점(8px) 표시
- 주변업체 출발 기준 버튼을 실제 계산 기준과 일치시키고 사용자 선택 전환 지원
- 방문 순서 제목과 초기화 버튼 좌우 정렬
- 선택 동선 지도: 작은 점선, 방향 화살표, 출발·도착 표시만 사용(경유지 번호 없음)
- 상세정보의 전화번호(데이터가 있을 경우) 및 주소 옆에 시연용 전화·차량 아이콘 표시. 버튼은 실제 외부 앱을 실행하지 않습니다.
- 기존 가상 데이터·PC·모바일 기능 유지

배포: ZIP을 풀어 저장소에 덮어쓰고 Commit/Push. 기존 config.js의 카카오 JavaScript 키가 설정된 경우 덮어쓰기 전 반드시 백업 후 복원하세요.

현재 표시 좌표와 이동선은 시연용입니다. 실제 환전업체 주소·도로 경로를 나타내지 않습니다.
