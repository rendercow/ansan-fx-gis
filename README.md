# FXGIS v0.4.1 — 모바일 위험등급 필터 및 지도 클러스터링

- PC 기존 화면 유지, 모바일 지도 상단에 **전체·고위험·주의·일반·좌표 미확인** 선택 버튼 추가.
- 고위험·주의·일반을 선택하면 지도 마커와 업체 목록에 동일한 조건 적용.
- 좌표 미확인은 지도에 찍을 수 없으므로 **업체 목록 탭**으로 자동 이동.
- 카카오 MarkerClusterer로 확대 수준에 따른 숫자 묶음 표시, 확대 시 개별 마커 확인.
- 전체 보기는 현재 필터링된 업체의 좌표 범위에 맞춰 지도 이동.
- 기존 모바일 마커 클릭 시 하단 상세정보 패널 유지.
- 기존 가상 업체 100개 및 상세 데이터는 그대로 유지. 업체들의 실제 주소가 25개 기준점에 중복되어 분포하며, 이는 테스트용 위치입니다.

## 배포
`config.js`에 기존 카카오 JavaScript 키를 유지해 주십시오. 새 ZIP의 `config.js`를 덮어쓸 경우 키를 다시 넣어야 합니다. GitHub Desktop Commit → Push 후 캐시 강제 새로고침으로 확인합니다.

실제 업무자료의 공개 GitHub 업로드는 금지합니다.
