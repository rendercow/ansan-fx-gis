# FXGIS v0.5.4 — 전국 적용 지역 필터 / 수도권 가상업체 기본 배포

- 시연용 기본 업체 100개: 안산 원곡동 38, 시흥 정왕시장 24, 부천 23, 인천 부평 10, 김포 4, 인천 계양 1.
- 주소 문자열에서 시·군 또는 광역시의 구를 추출해 PC/모바일 지역 필터를 자동 생성합니다.
- 기본 시연 좌표는 권역 중심 주변에 생성한 **가상 좌표**입니다. 실제 환전소 주소나 길찾기 목적지로 쓰면 안 됩니다.
- 실제 엑셀 업로드 시 시연 기본 자료를 대체하지만 GitHub 파일을 갱신하지는 않습니다.
- `config.js`의 카카오 JavaScript 키를 기존 값으로 유지하세요.
- `index.html`, `app.js`, `style.css`, `config.js`, `demo-data.json` 전체를 저장소 최상위에 업로드하세요.
- 모바일 첫 접속 시 자동으로 수도권 자료 100개가 표시되며 지도는 전체 분포로 맞춥니다.


## v0.5.5 모바일 지도 지역 필터
- 기존 검색창 및 위험도 칩은 유지합니다.
- 지도 내부 왼쪽 상단의 표시 건수 안내를 **지역 선택 드롭다운 + 선택 조건 업체 수**로 변경했습니다.
- 지역 목록은 불러온 업체 주소의 시·군·구 필드에서 자동 생성됩니다.
- 선택 조건은 지도와 업체 목록에서 공유됩니다.
- 전체 보기는 현재 검색·지역·위험도 조건에 해당하는 업체 마커를 화면에 맞춥니다.
- PC의 기존 지역 필터 및 화면 구성은 변경하지 않았습니다.
