# FXGIS v0.4.2 — 통계 필터 간소화 / 테스트 위치 분산

- PC 상단의 다섯 통계 상자를 **한 줄 선택형 필터**로 축소. 각 항목 클릭 시 업체 목록/지도 위험등급을 필터링합니다. 지도 좌표 확인은 위치가 있는 업체 전체를 보여줍니다.
- 기존 모바일 상단 위험등급 버튼과 마커 선택 시 하단 상세정보 패널 유지.
- 100개 가상 업체는 안산시 행정동 기준 주소 25개를 참조합니다. 카카오맵으로 해당 기준 주소의 좌표를 얻은 뒤 **시연 전용 좌표 오프셋**을 적용해 분산합니다. 표시 좌표는 실제 주소 위치와 일치하지 않으므로 길찾기·현장 점검에 사용하면 안 됩니다.
- 사용자 엑셀을 수동 업로드하면 위 시연용 분산 처리를 적용하지 않고 실제 주소 변환을 수행합니다.
- 앱은 테스트용 공개 데이터만 사용합니다.

## 배포
기존 `config.js` 키 보존 후 나머지 파일을 덮어쓰고 Commit → Push. JS/CSS 버전 0.4.2 캐시 구분 적용.
