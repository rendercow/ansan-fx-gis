# FXGIS v0.3 — 가상 데이터 자동시연 (PC/모바일)

1. ZIP을 풀고 **전체 파일**을 GitHub 저장소 `ansan-fx-gis` 최상위에 복사, Commit, Push 합니다.
2. 카카오 디벨로퍼스에 `https://rendercow.github.io` 도메인이 등록되어 있는지 확인합니다.
3. **모든 기기에서 지도 자동 표시를 원하면** `config.js`의 `kakaoJavaScriptKey: ''` 따옴표 안에 카카오 **JavaScript 키만** 입력하고 함께 배포합니다. 이는 공개형 브라우저 SDK 키이며 소스에 노출됩니다. **REST API 키, Admin 키 또는 개인정보를 절대 넣지 마세요.**
4. `config.js`를 비워 두면 기기마다 처음 한 번 `지도 API 설정`에서 JavaScript 키를 입력해야 합니다. 이후 그 브라우저에는 보관됩니다.
5. 엑셀 업로드 없이 `demo-data.json`의 **가상 업체 100개**가 자동 표시됩니다. 지도 연결 뒤에는 주소 25개 정도만 한 번 변환하여 업체 100개의 좌표에 연결합니다. 변환이 끝난 브라우저에는 좌표가 저장됩니다.
6. 같은 기준점 주소를 사용하는 업체는 구분해서 선택하도록 **지도 표시용 마커만 소폭 벌려서 표시**합니다. 실제 위치가 아니라는 점에 유의하세요.
7. 모바일에서는 상단 **지도 / 업체 목록 / 상세정보** 탭을 사용합니다.

**중요**: GitHub Pages는 기본적으로 누구나 공개접속 가능한 정적 페이지입니다. 테스트 파일, 테스트 이름, 테스트 주소 등 **가상 데이터만** 올리세요. 실제 업무자료는 기관의 보안승인, 사용자 인증과 DB 권한 통제가 갖추어진 뒤에만 처리해야 합니다.
