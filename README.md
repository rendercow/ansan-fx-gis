# 안산시 환전업자 GIS 위험관리 v0.1

## 실행 (GitHub Pages)
1. `index.html`, `style.css`, `app.js`, `안산시_가상환전업자_100개_위험관리_테스트.xlsx` 네 파일을 GitHub 리포지토리 **루트**에 업로드합니다.
2. Settings → Pages → Deploy from branch → main / (root) → Save.
3. https://developers.kakao.com 에서 앱을 만들고 **카카오맵 사용 설정 및 JavaScript 키**를 확인합니다. JavaScript SDK 허용 도메인에 `https://계정.github.io` (실제 주소의 origin)를 등록합니다. 세부 메뉴는 카카오 개발자 콘솔 UI에 따라 달라질 수 있습니다.
4. 배포된 GitHub Pages에서 **지도 API 설정**을 클릭하여 JavaScript 키를 입력합니다. **REST API 키/관리자 키는 입력하지 마세요.**
5. 엑셀 불러오기 → 포함된 가상 엑셀 선택 → '미확인 주소 변환' 버튼 클릭.
6. 지도 마커 또는 왼쪽 목록을 클릭해 업체 상세정보를 열람하고, 검색 및 위험도 필터를 시험합니다.

## 중요 사항
- 엑셀은 브라우저에서 직접 읽으며 **서버 또는 Supabase에 업로드하지 않습니다**.
- 입력한 JavaScript 키, 성공한 주소 변환 좌표는 **해당 브라우저의 localStorage**에 저장됩니다.
- 주소가 실제 유효한 건물 주소로 검증된 것이 아니므로 100개가 모두 지도에 표시된다는 보장은 없습니다. 해당 문제는 프로그램 오류가 아닐 수 있습니다. 실패 수는 상태 메시지에 표시됩니다.
- 안산시 범위를 벗어난 주소 변환 결과는 표시하지 않도록 검증합니다.
- 브라우저가 카카오 지도 도메인과 SheetJS CDN에 접근 가능해야 합니다. 네트워크 정책에 따라 별도 허용이 필요합니다.
- 실제 업무자료, 대표자 개인정보, 실적, 점검이력 등은 **기관 보안 승인 전 업로드하지 마세요**. GitHub Pages는 인증/접근통제 기능이 없는 정적 배포이며 현재 시제품에 로그인은 없습니다.
- CSV 다운로드에는 현재 좌표 변환 결과가 포함됩니다. 별도의 서버 데이터 저장 기능은 없습니다.
- 위험점수는 시제품 엑셀 '위험도평가' 시트의 계산된 값을 읽습니다. 법적·업무적 위험평가 결과가 아닙니다.

## 사용 기술
Vanilla JS · Kakao Maps JavaScript SDK (`services` 주소변환) · SheetJS 0.20.3 · GitHub Pages
