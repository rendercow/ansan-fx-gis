# FXGIS v0.5.0 모바일 통합 개선

모바일: 중복 범례 제거, 검색창 가로 밀림 방지, 검색 버튼, 조회형 업체 목록, 하단 메뉴 고정, 상세 패널 손잡이 스와이프 닫기, GPS·선택 업체 기준 주변업체 조회(직선거리), 방문 순서 선택과 지도상 직선 연결. PC: 기존 업무 화면 유지.

## 배포
`config.js`의 기존 JavaScript SDK 키를 보관한 뒤 나머지를 GitHub 저장소에 덮어씌우고 Commit/Push. `config.js` 키가 비어 있으면 다시 입력해야 합니다.

가상 테스트 데이터 100개와 표시용 분산 좌표는 실제 방문 주소가 아니며, 방문 동선 역시 도로 경로가 아닌 직선 연결입니다. 실제 업무자료와 사용자 계정은 포함하지 않았습니다.
