# FXGIS v0.4 — PC/모바일 통합 현장 시연판

- v0.3의 기존 PC 3열 화면, 기본 가상업체 100개 자동 로딩, 카카오맵 API, 수동 엑셀 업로드를 유지합니다.
- 모바일은 지도 중심으로 재구성했습니다: 상단 검색, 위험도·지역 필터, 지도 위 결과수, 하단 고정 탭.
- 모바일 지도 마커를 누르면 지도 위에 하단 상세정보 패널이 나타납니다. 패널 닫기(×) 가능.
- `config.js`에 카카오 JavaScript 키를 설정하면 공유 링크에서도 자동 연결됩니다. REST/Admin 키는 절대 입력하지 마세요.
- `style.css`, `app.js`에 v0.4.0 캐시 구분자를 부여했습니다. 기존 GitHub 저장소 최상위 파일들을 **모두** 교체 후 Commit/Push 하세요.
- 시연용 공개 가상 데이터만 포함합니다. 실제 업무자료는 절대로 GitHub Pages 공개 정적 파일에 넣지 마세요.
- **검증 한계:** JavaScript 문법/정적 파일 구성 점검을 거쳤지만, 카카오 API를 통한 실제 기기·브라우저 동작은 배포 후 확인해야 합니다.
